Release Workflow
feat → Bump Version → CI → Argo CD Sync
پس از توسعه در Forge، commit با پیام feat: روی branch feature بزنید. Pipeline در GitLab اجرا می‌شود؛ job دستی bump-version را با متغیر ENV (dev / stg / prd) Run کنید. CI ادامه می‌یابد و نسخه جدید به Argo CD می‌رود — در Argo CD اپ را Sync کنید.
  1. Commit با feat: پیام commit باید با feat: شروع شود (مثلاً feat(ven-100): create contract api) — Forge این فرمت را رعایت می‌کند.
  2. Pipeline: پس از push، pipeline مربوط به branch در لیست زیر ظاهر می‌شود (مراحل build/test).
  3. Bump version: job دستی Bump Version را باز کنید → ENV=dev یا stg یا prd → Run Job.
  4. CI خودکار: پس از bump، مراحل بعدی pipeline (deploy artifact و …) خودکار اجرا می‌شوند.
  5. Argo CD Sync: در Argo CD محیط مربوطه (dev/stg/prd) را باز کنید و Application را Sync کنید تا نسخه جدید live شود.
